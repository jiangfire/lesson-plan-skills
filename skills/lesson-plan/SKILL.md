# 教案设计（融合教育学原则）

帮助**没当过老师的培训者**快速产出一节课的完整装备：**教案（.md，给讲师备课和后续修改）+ 课件（.html 幻灯片，给学员看）**。核心思路：只保留**少而精、条条能对应到具体教学动作**的 6 条原则，并把原则落点写进产出物本身——教案里有原则对照表和设计意图，幻灯片标题旁标注原则编号。

## 何时使用

- 用户要为**企业内训、成人培训、工作坊**设计一节课或系列课。
- 用户提到"教育学原则 / 教学原理 / 培训方法 / 成人学习"等。
- 用户要求产出**教案 / 课件 / PPT**。

不要用于：学历教育的完整学期大纲、考试命题、纯知识讲解（无实操环节）。

## 产出物（两份）

| 文件 | 受众 | 说明 |
| --- | --- | --- |
| `教案-<主题>.md` | 讲师 | 以 `教案设计.md` 为模板填写，**可自由编辑** |
| `课件-<主题>.html` | 学员 | 以 `references/slide-shell.html` 为壳生成，双击即播，离线可用 |

**产出落点**：两份产出和 `素材库/` 都在**调用者的当前工作目录**（用户的项目），不写入 skill 自身目录；skill 目录里的模板和素材库 README 只读复用。用户项目下没有 `素材库/` 时创建它（可从 skill 目录复制 `素材库/README.md` 作为规则说明）。

## 素材库

讲师是懂得最多的人——`素材库/` 是背景知识进入产出物的通道，完整规则见 `素材库/README.md`：

- **讲师自备**的直接可用；**AI 联网搜集的**文件头标来源 URL + 检索日期 + "状态：待审查"，**必须经讲师确认后才可用于生成**（生成前列出素材清单请其审查）；
- **素材内容优先于模型自身知识**，冲突时以素材为准；但**不得整段复制进产出物**，提取要点即可；
- 用到的文件列入教案"十、参考资料"。

## 执行流程

1. **补齐最小信息**（默认值见下方"输入参数"表）：从对话中识别主题、时长、学员群体。信息不足时**最多通过 1 次提问集中补齐**（3–4 题）。

2. **读两个模板**：
   - `教案设计.md`（本 Skill 目录）——教案结构模板，已含 **6 条原则对照表**（第二节）和 **40 分钟时间节奏**（第五节：3+2+10+12+8+5）。用户指定其他时长（20/60/90）时按同比例缩放；
   - `references/slide-shell.html`——幻灯片放映壳，**只读不改**（仅 `<title>` 替换为课题名；内联的 Reveal.js 库、固定主题 CSS、播放器 JS 一律不动）。壳已固化：固定画布与主题、fragment、练习倒计时、S 键讲师提示、打印导出；

3. **搜集素材（AI 找，讲师审）**：
   - 先列出**用户当前工作目录下**的 `素材库/` 目录（没有则创建），阅读与本课题相关的已有素材；
   - 相关素材不足时**联网搜索补齐**：真实案例、行业数据、研究结论、常见误区——**优先搜"反直觉弹药"**（学员第一反应会"咯噔"的事实，见 `references/设计经验.md` 第 9 条），整理成 md 存入 `素材库/`，文件头标注来源 URL + 检索日期 + "状态：待审查"；
   - 联网搜集的每份素材，AI 先逐条核对**来源 URL 可达性**与**关键数字转载一致性**，产出《素材审查记录》（初核结论 + 待讲师定夺事项，如多来源数字口径冲突）——**AI 初核不等于讲师终审**，文件头状态翻转必须待讲师确认；
   - **向讲师列出素材清单请其审查**（确认 / 剔除 / 换方向重搜），讲师确认后才进入下一步；讲师已有素材充足时可跳过搜索。

4. **先写教案** `.md`：
   - 用用户真实信息填"教案信息"表；缺失信息用 `＿＿＿` 占位，**不编造**用户单位的课程事实、岗位名称、学员人数；
   - 将"教学过程"各环节的教师活动/学员活动替换为用户课题的真实内容；
   - **原则对照表的"原则"和"翻译成人话"两列不变**，"对应教案落点"列按课题改写；
   - **每次提问/练习环节必须设计"答案展示"动作**，时序按设计经验第 7 条（收敛型紧跟练习页、发散型放分享后）；每组块至少 1 个真实案例（优先素材库）；
   - 设计意图列、教学反思表结构保留，措辞贴合课题；
   - **末尾"十、参考资料"列出用到的素材文件及用途**；没用素材则写"本次未使用素材库"。

5. **再从教案生成课件** `.html`：复制放映壳，把标记区内的示例幻灯片替换为本课内容（页序直接映射教案第五节的环节，见下"幻灯片结构"），并把壳的 `<title>`（标记区外）替换为课题名。素材中的关键事实、数据、案例优先上屏，但仍受下方内容约束。

6. **校验**：生成后自查页数（40 分钟课 ≈ 15–18 页）、每页要点数、练习页是否带 `data-timer`、分步讲解处是否用了 `fragment`、答案示例页时序（设计经验第 7 条），并**逐条过一遍 `references/设计经验.md` 的 10 条设计经验**；有 node 时抽出内联 `<script>` 跑 `node --check`；**逐页渲染验收**：本地静态服务 + 浏览器逐页截图（或请用户完整翻页），确认每一页都正常渲染——首页正常不代表后面正常，纯 DOM 结构校验发现不了渲染问题；最后请用户双击课件验证翻页、fragment、练习倒计时、S 键讲师提示和 `?print-pdf` 打印导出。

7. **交付**：回复中说明**思路 + 原则落点**（比文件本身更重要），列出用到的素材及其审查状态，并按 `references/交付话术.md` 给出用法说明和新手提醒。

## 幻灯片结构（映射 40 分钟节奏）

```
封面 → 痛点案例(①) → 目标+三组块地图(⑤)
→ 组块一：概念页（或画成图解页）→ 演示/案例页（冲击数据可上大数字页）→ 练习页 → 答案示例页(②③④)
→ 组块二：方法页（或画成图解页）→ 模板页 → 练习页 → 答案示例页(③⑤⑥)
→ 组块三：综合任务页 → 提问分享页 → 教师版示例清单页（清单可画成图解页）(①⑥)
→ 总结+课后行动(①④)
```

- 只用壳里定义好的 7 种版式：`layout-cover` / `layout-bullets` / `layout-cols` / `layout-task` / `layout-closing` / `layout-stat`（大数字页）/ `layout-diagram`（内联 SVG 图解页）；
- **视觉节奏**：深色主题下文字页连续出现会单调——每个组块至少穿插 1 个视觉页（大数字页或图解页，落点见结构图括注）；有冲击力的数据（百分比、对比、降幅）优先上 `layout-stat` 砸满屏，别埋在要点里（一页最多 3 个数字，壳会按个数自动降档字号）；机制、流程、关系优先画成 `layout-diagram` 的内联 SVG（用主题色，不破坏单文件离线）；
- 要点里用 `<strong>` 标 1–2 个关键词（琥珀色高亮），制造视觉层级；
- **分步讲解一律用 `class="fragment"`**：推导过程、逐条讲评的参考答案、先问后亮的揭晓内容，按讲解顺序给要点逐条加 fragment（两栏页的"揭晓栏"可整栏加 fragment）——这是课件区别于静态讲义的核心体验；一页内 fragment 不超过 5 个，超了就拆页；
- **练习页一律用 `layout-task` + `data-timer="分钟数"`**——进入该页自动开始倒计时（组块二最容易超时）；
- **每个练习页后必须有答案示例页**（`layout-bullets` 或 `layout-cols`）：给出参考答案、正误对比或教师版示例；时序按设计经验第 7 条（收敛型紧跟练习页，发散型放提问分享之后）；
- 每页 `<aside class="note">` 写一行讲师提示（时长 + 设计意图），放映时按 **S** 在底部唤出。

## 幻灯片内容约束（防溢出、防过载，必须遵守）

- **一页一信息**：一页只讲一个观点；标题即结论，不写描述性标题；
- 要点页 **≤6 条、每条 ≤20 字**；写不下就拆成两页，绝不缩小字号硬塞；
- 细节、话术、展开解释**一律不进页面**，进教案 md 和该页 note；
- 放映壳是固定 1280×720 画布等比缩放——超出的内容会溢出画布，所以宁少勿多；
- 原则编号 ①–⑥ 用 `<span class="tag">①</span>` 标注在相关标题/要点旁。

## 设计经验

历次课程沉淀的 10 条设计经验在 `references/设计经验.md`——生成时（步骤 3–5）参照，校验时（步骤 6）逐条过一遍。

## 图片（可选增强）

课件默认纯文字交付；需要配图时按 `references/配图.md` 执行。**嵌入方式唯一：base64 data URI，禁止外链 URL 和本地文件引用**——单文件离线铁律不破。

## 输入参数（最小化）

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| 培训主题 | 是 | — | 如"用 LLM 提升岗位效率" |
| 课时长度 | 否 | 40 分钟 | 支持 20/40/60/90 |
| 学员群体 | 否 | 企业内部成人 | 影响学情分析措辞 |
| 教学形式 | 否 | 讲授+实操+提问 | 实操/纯讲授/工作坊 |
| 具体知识内容 | 否 | 待填 | 有则填入，无则留占位符 |
| 指定原则 | 否 | 模板固定 6 条 | 用户明确指定时才替换 |
| 素材库 | 否 | 自动检索，不足则联网搜集 | 搜集结果需讲师审查后采用 |

## 运行约束

- 课件为**单文件 HTML**：不引入外部 CSS/JS/字体/图片，离线可播（Reveal.js 已内联进放映壳，禁止改成 CDN 引用）；**不修改放映壳的主题 CSS/播放器 JS**，只替换标记区内的幻灯片内容和 `<title>`（课题名）。
- 壳更新后已有课件**不自动同步**；如需同步（维护升级），用标记区拼接：保留课件的幻灯片区域与 `<title>`，其余整体替换为新壳，替换后必须逐页回归验收。
- 教案为**纯 Markdown**，用户要改就改 md，改完如需同步课件再重新生成 html。
- 产出为**一次性**文件，不维护课程进度或多版本看板。产出与素材库一律写入**调用者当前工作目录**，skill 自身目录只读。
- 读用户已有教案/附件/素材时，直接用现有文件读取能力，不写解析脚本。
