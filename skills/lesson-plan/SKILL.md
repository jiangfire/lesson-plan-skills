# 教案设计（融合教育学原则）

帮助**没当过老师的培训者**快速产出一节课的完整装备：**教案（.md，给讲师备课和后续修改）+ 课件（.html 幻灯片，给学员看）**。核心思路：只保留**少而精、条条能对应到具体教学动作**的 6 条原则，并把原则落点写进产出物本身——教案里有原则对照表和设计意图，幻灯片标题旁标注原则编号。

## 何时使用

- 用户要为**企业内训、成人培训、工作坊**设计一节课或系列课。
- 用户提到"教育学原则 / 教学原理 / 培训方法 / 成人学习"等。
- 用户要求产出**教案 / 课件 / PPT**。

不要用于：学历教育的完整学期大纲、考试命题、纯知识讲解（无实操环节）。

## 产出物（两份）

| 文件 | 受众 | 说明 |
| --- | --- | --- |
| `教案-<主题>.md` | 讲师 | 以 `教案设计.md` 为模板填写，**可自由编辑** |
| `课件-<主题>.html` | 学员 | 以 `references/slide-shell.html` 为壳生成，双击即播；基于 Reveal.js（已内联，离线可播），支持 fragment 分步浮现、`?print-pdf` 打印导出 |

**产出落点**：两份产出和 `素材库/` 都在**调用者的当前工作目录**（用户的项目），不写入 skill 自身目录；skill 目录里的模板和素材库 README 只读复用。用户项目下没有 `素材库/` 时创建它（可从 skill 目录复制 `素材库/README.md` 作为规则说明）。

## 素材库（讲师自备 + AI 搜集，讲师审查）

讲师是懂得最多的人——`素材库/` 目录是背景知识进入产出物的通道，规则详见 `素材库/README.md`：

- **两个来源**：讲师自己放的（直接可用）；AI 联网搜集的（文件头标注来源 URL、检索日期、**状态：待审查**）；
- **AI 搜集必须经讲师审查**：生成前列出素材清单（文件名 + 一句话内容 + 来源），讲师确认或剔除后才用于生成；
- **素材内容优先于模型自身知识**，冲突时以素材为准；
- 用到的文件列入教案"十、参考资料"；与课题无关的素材不强行使用；
- 搜索优先权威来源（官方报告、学术研究、主流媒体），每个素材文件必须带来源 URL 供讲师核查。

## 执行流程

1. **补齐最小信息**（见下方"输入参数"）：从对话中识别主题、时长、学员群体。信息不足时**最多通过 1 次提问集中补齐**（3–4 题）。默认值：**时长 40 分钟**、**学员企业内部成人**、**形式讲授+实操+提问**。

2. **读两个模板**：
   - `教案设计.md`（本 Skill 目录）——教案结构模板，已含 **6 条原则对照表**（第二节）和 **40 分钟时间节奏**（第五节：3+2+10+12+8+5）。用户指定其他时长（20/60/90）时按同比例缩放；
   - `references/slide-shell.html`——幻灯片放映壳，**只读不改**（内联的 Reveal.js 库、固定主题 CSS、播放器 JS 一律不动）。壳已固化：1280×720 画布等比缩放、固定主题（配色/字号/中文字体）、fragment 分步浮现、练习倒计时、S 键讲师提示、`?print-pdf` 打印导出；

3. **搜集素材（AI 找，讲师审）**：
   - 先列出**用户当前工作目录下**的 `素材库/` 目录（没有则创建），阅读与本课题相关的已有素材；
   - 相关素材不足时**联网搜索补齐**：真实案例、行业数据、研究结论、常见误区——**优先搜"反直觉弹药"**（学员第一反应会"咯噔"的事实，见设计经验 9），整理成 md 存入 `素材库/`，文件头标注来源 URL + 检索日期 + "状态：待审查"；
   - **向讲师列出素材清单请其审查**（确认 / 剔除 / 换方向重搜），讲师确认后才进入下一步；讲师已有素材充足时可跳过搜索。

4. **先写教案** `.md`：
   - 用用户真实信息填"教案信息"表；缺失信息用 `＿＿＿` 占位，**不编造**用户单位的课程事实、岗位名称、学员人数；
   - 将"教学过程"各环节的教师活动/学员活动替换为用户课题的真实内容；
   - **原则对照表的"原则"和"翻译成人话"两列不变**，"对应教案落点"列按课题改写；
   - **每次提问/练习环节必须设计"答案展示"动作**：练习后先展示参考答案或正误示例，讲评完再进下一环节；每组块至少 1 个真实案例（优先素材库）；
   - 设计意图列、教学反思表结构保留，措辞贴合课题；
   - **末尾"十、参考资料"列出用到的素材文件及用途**；没用素材则写"本次未使用素材库"。

5. **再从教案生成课件** `.html`：复制放映壳，把标记区内的示例幻灯片替换为本课内容（页序直接映射教案第五节的环节，见下"幻灯片结构"）。素材中的关键事实、数据、案例优先上屏，但仍受下方内容约束。

6. **校验**：生成后自查页数（40 分钟课 ≈ 15–18 页）、每页要点数、练习页是否带 `data-timer`、分步讲解处是否用了 `fragment`（答案讲评、推导过程、揭晓内容）、答案示例页时序是否正确（收敛型紧跟练习页，发散型在提问分享之后），并逐条过一遍下方"设计经验"。

7. **交付**：回复中说明**思路 + 原则落点**（比文件本身更重要），列出用到的素材及其审查状态，并给出新手提醒（见"交付话术要点"）。

## 幻灯片结构（映射 40 分钟节奏）

```
封面 → 痛点案例(①) → 目标+三组块地图(⑤)
→ 组块一：概念页 → 演示/案例页 → 练习页 → 答案示例页(②③④)
→ 组块二：方法页 → 模板页 → 练习页 → 答案示例页(③⑤⑥)
→ 组块三：综合任务页 → 教师版示例清单页 → 提问分享页(①⑥)
→ 总结+课后行动(①④)
```

- 只用壳里定义好的 7 种版式：`layout-cover` / `layout-bullets` / `layout-cols` / `layout-task` / `layout-closing` / `layout-stat`（大数字页）/ `layout-diagram`（内联 SVG 图解页）；
- **视觉节奏**：深色主题下文字页连续出现会单调——每个组块至少穿插 1 个视觉页（大数字页或图解页）；有冲击力的数据（百分比、对比、降幅）优先上 `layout-stat` 砸满屏，别埋在要点里（一页最多 3 个数字，壳会按个数自动降档字号）；机制、流程、关系优先画成 `layout-diagram` 的内联 SVG（用主题色，不破坏单文件离线）；
- 要点里用 `<strong>` 标 1–2 个关键词（琥珀色高亮），制造视觉层级；
- **分步讲解一律用 `class="fragment"`**：推导过程、逐条讲评的参考答案、先问后亮的揭晓内容，按讲解顺序给要点逐条加 fragment（两栏页的"揭晓栏"可整栏加 fragment）——这是课件区别于静态讲义的核心体验；一页内 fragment 不超过 5 个，超了就拆页；
- **练习页一律用 `layout-task` + `data-timer="分钟数"`**——进入该页自动开始倒计时（组块二最容易超时）；
- **每个练习页后必须紧跟一页答案示例页**（`layout-bullets` 或 `layout-cols`）：给出参考答案、正误对比或教师版示例，学员对完答案再翻篇；
- 每页 `<aside class="note">` 写一行讲师提示（时长 + 设计意图），放映时按 **S** 在底部唤出。

## 幻灯片内容约束（防溢出、防过载，必须遵守）

- **一页一信息**：一页只讲一个观点；标题即结论，不写描述性标题；
- 要点页 **≤6 条、每条 ≤20 字**；写不下就拆成两页，绝不缩小字号硬塞；
- 细节、话术、展开解释**一律不进页面**，进教案 md 和该页 note；
- 放映壳基于 Reveal.js，固定 1280×720 画布等比缩放——超出的内容会溢出画布，所以宁少勿多；
- 原则编号 ①–⑥ 用 `<span class="tag">①</span>` 标注在相关标题/要点旁。

## 图片（可选增强，base64 内嵌）

- **只嵌值得的图**：图片服务于"咯噔点"或抽象概念（如洞穴寓言插画、实验数据图），一页最多一张，不为配图而配图；纯文字能讲清的页面不加图；
- **嵌入方式唯一**：base64 data URI（`<img src="data:image/...;base64,...">`），**禁止外链 URL 和本地文件引用**——单文件离线铁律不破；
- **流程**：生成时先出**建议配图清单**（哪页、什么图、起什么作用），写进教案和该页 note；讲师自己找图（提醒版权：可商用或自制）后放入 `素材库/images/`，AI 压缩（宽 ≤1600px、单张 ≤300KB）后转 base64 嵌入对应页面；
- 没图不影响交付：课件先以纯文字版交付，图片是增量增强。

## 输入参数（最小化）

| 参数 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| 培训主题 | 是 | — | 如"用 LLM 提升岗位效率" |
| 课时长度 | 否 | 40 分钟 | 支持 20/40/60/90 |
| 学员群体 | 否 | 企业内部成人 | 影响学情分析措辞 |
| 教学形式 | 否 | 讲授+实操+提问 | 实操/纯讲授/工作坊 |
| 具体知识内容 | 否 | 待填 | 有则填入，无则留占位符 |
| 指定原则 | 否 | 模板固定 6 条 | 用户明确指定时才替换 |
| 素材库 | 否 | 自动检索，不足则联网搜集 | 搜集结果需讲师审查后采用 |

## 交付话术要点（回复用户时必说）

1. **先给结论**：只用死磕哪几条原则、为什么是这几条（覆盖成人培训四个致命问题：与我无关、听不懂用不上、练了不知对错、信息过载走神）。
2. **两份文件怎么用**：md 是备课和修改的主文件；html 双击即播，←/→ 翻页、带 fragment 的要点逐条浮现、S 看讲师提示、练习页自动倒计时、答案示例页对完答案再翻篇；打印导出：地址栏加 `?print-pdf` 后 Ctrl+P 即可生成每页一张的 PDF（fragment 会全部展开）。
3. **素材使用情况**：本次用了素材库里的哪些文件、用在了哪、哪些还是"待审查"；提醒讲师新资料丢进 `素材库/` 可重出。
4. **新手提醒**：
   - 上课前读一遍教案各环节的"设计意图"，就不易照本宣科；
   - 练习后忍住别直接翻页——答案示例页是学员获得感最强的时刻；
   - 时间宁可留白，组块二最容易超时——练习页倒计时别按掉；
   - 验收标准要写进教案（对应原则④）。
5. **可选后续**：① 压缩/扩成其他时长；② 生成配套任务卡；③ 换课题重出一版。

## 设计经验（历次课程沉淀，生成时逐条自查）

1. **时间预算守恒**：新增任何环节（案例页、答案展示）必须从现有环节显性扣减，各环节之和恒等于课时。答案展示并入练习环节预算，练:评 ≈ 2:1；禁止用"（含上）"藏匿新环节的时间。
2. **悬念分步揭晓**：先问后亮的数据、答案、反转结论，用 `class="fragment"` 与问题同页分步浮现（点一下才揭晓）；跨页的"先提问、后翻页揭晓"仍然成立（如开场举手后再翻数据页）。无论哪种，都禁止"问题和答案同时可见"。
3. **类比要标断裂点**：用类比讲概念时，该页讲师提示必须写清"类比在哪里不成立"（如：人猜词有语义理解兜底，模型没有），防止学员带走错误心智模型。
4. **支架要覆盖中间态**：给学员的判断模板不能只有"全行/全不行"两档，必须有中间档规则（如"任何一问为'是' → 人必须复核"）。生成后用模板自带的练习题自查：每道题的答案是否都能被模板规则直接推出。
5. **同组练习性质一致**：一组练习的各小题考查同一性质（概率题就全是概率题），不混入开放式观点题——讨论跑偏就收不回来。
6. **态度目标要有中间回扣**：情感类目标（减压、建立信心）不只靠首尾呼应，中间环节要有产出物承载（如岗位清单 = 掌控感的证据），收尾时点破这层关系。
7. **答案页的时序分收敛/发散**：收敛型练习（有标准答案）练习页后紧跟答案页；发散型产出（如岗位清单、方案设计）示例页放在**学员提问分享之后**给——提前亮出教师版示例会框死学员思路，也剧透分享环节。
8. **提问不破坏节奏（提问节奏守则）**：① 题目随计时同时亮出，全班并行思考/写——提问只"收"不"等"，不占额外时间；② 冷叫三步：先问全班 → 给够思考时间（已含在计时内）→ 最后才点名，绝不先点名再出题（先点名其他人立刻放松）；③ 无退出 + 兜底：答不出给一次提示或请旁人补一句，冷场 5 秒教师自答继续，兜底话术写进该页讲师提示；④ 一次提问只点 1–3 人、每人 20–30 秒，提问时间从"评"的预算里出，不新增环节。
9. **成人要"恍然大悟"密度（反直觉原则）**：成人学员对"老生常谈"免疫——只讲"是什么、要小心"会显得小儿科。每个组块至少给 1 个能让学员心里"咯噔"一下的点，**验收标准是学员的第一反应："我怎么没想到"→"原来如此"**——先意外、后通透，缺了任何一半都不合格：只意外不通透是噱头，只通透不意外是常识。写法是**先制造预期、再打破它**：先让学员以为"能写代码的模型当然会数字母"，再揭晓它数不清 strawberry 里有几个 r；先让学员以为"用 AI 总没错"，再亮出哈佛×BCG 758 名顾问边界外正确率反降 19 个百分点。三类弹药：机制层的为什么（"训练目标只有'像真的'，幻觉是机制的必然"）、反直觉案例、带样本量的实验数据。必要时加第四类"不明觉厉"弹药：**哲学概念**——但必须贴肉，恰好解释本课的某个机制，不做装饰（如：柏拉图洞穴寓言 = 模型的世界只有文本的影子；塞尔中文房间 = 完美操作符号 ≠ 理解；苏格拉底"知道自己不知道" = 模型没有元认知，把关必须是人）。哲学概念一次课最多 2–3 个，每个一句话讲透，展开即过载。**弹药分层投放**：主弹药（每块必给的咯噔点）上屏进页面；备用弹药（更深的纵深，如中文房间）只写进该页讲师提示和教案，不上屏——学员主动追问时才给，追问才给的内容比硬塞的印象深得多。生成时逐条自查：这个点换成学员第一次听，会"咯噔"吗？不会就换。收尾给学员 1 句能拿去跟同事讲的"谈资金句"（社交货币）——金句本身也要过"咯噔"检验。

## 运行约束

- 课件为**单文件 HTML**：不引入外部 CSS/JS/字体/图片，离线可播（Reveal.js 已内联进放映壳，禁止改成 CDN 引用）；**不修改放映壳的主题 CSS/播放器 JS**，只替换标记区内的幻灯片内容。
- 教案为**纯 Markdown**，用户要改就改 md，改完如需同步课件再重新生成 html。
- 素材库内容视为事实来源，优先采用；但**不得把素材内容整段复制进产出物**，提取要点即可。AI 搜集的素材未经讲师审查确认不得使用。
- 产出为**一次性**文件，不维护课程进度或多版本看板。产出与素材库一律写入**调用者当前工作目录**，skill 自身目录只读。
- 读用户已有教案/附件/素材时，直接用现有文件读取能力，不写解析脚本。
