# 配图规则（可选增强）

课件默认纯文字交付，没图不影响交付；配图是增量增强。

- **只嵌值得的图**：图片服务于"咯噔点"或抽象概念（如洞穴寓言插画、实验数据图），一页最多一张，不为配图而配图；纯文字能讲清的页面不加图；
- **嵌入方式唯一**：base64 data URI（`<img src="data:image/...;base64,...">`），**禁止外链 URL 和本地文件引用**——单文件离线铁律不破；
- **流程**：生成时先出**建议配图清单**（哪页、什么图、起什么作用），写进教案和该页 note；讲师自己找图（提醒版权：可商用或自制）后放入 `素材库/images/`，AI 压缩（宽 ≤1600px、单张 ≤300KB）后转 base64 嵌入对应页面。压缩与 base64 转换允许用一次性命令完成，不受 SKILL.md"不写解析脚本"约束（那条只针对读教案/素材）。
