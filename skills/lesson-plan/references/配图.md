# 配图规则（可选增强）

课件默认纯文字交付，没图不影响交付；配图是增量增强。

- **只嵌值得的图**：图片服务于"咯噔点"或抽象概念（如洞穴寓言插画、实验数据图），一页最多一张，不为配图而配图；纯文字能讲清的页面不加图；
- **嵌入方式唯一**：base64 data URI（`<img src="data:image/...;base64,...">`），**禁止外链 URL 和本地文件引用**——单文件离线铁律不破；
- **嵌入铁律：禁止给 `.slides>section` 加 `position:relative`**——reveal 中该页会变成流内元素占满画布高，其后所有页的自动 top 整体下移一屏，表现为翻到第 2 页起全部白屏。需要全幅背景图时用 `position:absolute; inset:0`（不占流；配 `opacity:.3~.35` 铺底最稳，封面尤其适用，避免与居中标题冲突）；局部配图放流内，用壳自带 img 样式（`max-height:340px`），并给页面留高度预算（1280×720 减去上下 60px 内边距，可用高约 600px）；
- **AI 生成图三查**（生成器普遍在右下角带工具水印）：① **水印**——裁掉底部水印条再嵌入；② **底色**——深色主题配深底图（提示词写明背景色；已生成的白底图可从边缘泛洪填充替换为目标底色，注意别误伤图内浅色元素）；③ **一致性**——同工具同风格串，第一张定稿后作风格参考，保证一组图像一套；
- **嵌入后必须真实浏览器逐页截图验收**：首页正常不代表后面正常，纯 DOM 结构校验发现不了渲染问题；截图偶发白屏多为合成瞬态，原地重截确认即可；
- **流程**：生成时先出**建议配图清单**（哪页、什么图、起什么作用），写进教案和该页 note；讲师自己找图（提醒版权：可商用或自制；AI 生成图确认所用工具的商用条款）后放入 `素材库/images/`，AI 压缩（宽 ≤1600px、单张 ≤300KB）后转 base64 嵌入对应页面。压缩与 base64 转换允许用一次性命令完成，不受 SKILL.md"不写解析脚本"约束（那条只针对读教案/素材）。
