# lesson-plan-skills

一个面向**企业内训 / 成人培训新手讲师**的课程设计 Agent Skill：一次产出一节课的完整装备——可编辑的**教案（Markdown）** + 可直接放映的**课件（单文件 HTML 幻灯片）**。

核心思路：只保留少而精、条条能对应到具体教学动作的 6 条教育学原则，并把原则落点写进产出物本身——教案里有原则对照表和设计意图，幻灯片标题旁标注原则编号。

## 产出物

| 文件 | 受众 | 说明 |
| --- | --- | --- |
| `教案-<主题>.md` | 讲师 | 以 `教案设计.md` 为模板填写，备课和修改的主文件 |
| `课件-<主题>.html` | 学员 | 以 `references/slide-shell.html` 为壳生成，双击即播 |

## 课件能力（Reveal.js 单文件壳）

- **离线可播**：Reveal.js 5 已内联，不依赖任何外部 CSS/JS/字体，没网的投影仪也能放；
- **固定 1280×720 画布 + 等比缩放**：任何分辨率下不错位；
- **固定主题**：配色 / 字号 / 中文字体固化在壳里，每份课件风格统一；
- **fragment 分步讲解**：推导过程、答案讲评、先问后亮的揭晓逐条浮现——这是课件区别于静态讲义的核心体验；
- **练习页自动倒计时**：`data-timer="分钟数"`，进页即走表；
- **讲师提示**：每页 `<aside class="note">`，放映时按 **S** 在底部唤出；
- **打印导出 PDF**：地址栏加 `?print-pdf` 后 Ctrl+P，每页一张、fragment 全部展开。

## 教学设计原则（沉淀在 SKILL.md 的"设计经验"）

- **时间预算守恒**：新增任何环节必须从现有环节显性扣减，练 : 评 ≈ 2:1；
- **提问节奏守则**：题目前置（随计时亮出）、冷叫三步（先问全班 → 给思考时间 → 最后点名）、冷场 5 秒教师自答兜底、一次只点 1–3 人——提问不破坏节奏；
- **"恍然大悟"密度**：成人学员对老生常谈免疫，每个组块至少 1 个反直觉"咯噔"点，验收标准是学员第一反应"我怎么没想到"→"原来如此"；
- **四类弹药**：机制层的为什么 / 反直觉案例 / 带样本量的实验数据 / 哲学概念（贴肉、最多 2–3 个、一句话讲透）；
- **弹药分层投放**：主弹药上屏，备用弹药只写进讲师提示，学员追问时才给；
- **答案页时序分收敛/发散**：有标准答案的紧跟练习页，发散型产出放在提问分享之后。

## 目录结构

```
SKILL.md                 # Skill 主文件：流程、约束、设计经验
教案设计.md              # 教案模板（含 6 原则对照表 + 40 分钟节奏）
references/
  slide-shell.html       # Reveal.js 放映壳（只读，生成时只替换标记区内容）
素材库/                  # 背景资料：讲师自备 + AI 搜集（需讲师审查）
  README.md              # 素材库规则
```

具体课程的产出（`教案-*.md` / `课件-*.html`）和素材内容不入库，由 `.gitignore` 排除。

## 使用方式

在支持 Agent Skills 的环境中（如 Kimi Code），直接说：

> 帮我设计一节《用 LLM 提升岗位效率》的课，40 分钟，学员是公司内部员工。

Agent 会按 `SKILL.md` 的流程执行：补齐最小信息（最多集中提问 1 次）→ 读模板 → 搜集素材并请你审查 → 先写教案 → 再生成课件 → 自查后交付。

支持自定义：课时长度（20/40/60/90 分钟，默认 40）、学员群体、教学形式（默认讲授+实操+提问）。

## 素材库规则

- **两个来源**：讲师自己放的（直接可用）；AI 联网搜集的（文件头标注来源 URL、检索日期、状态：待审查）；
- **AI 搜集的素材必须经讲师审查**后才用于生成，素材内容优先于模型自身知识；
- 用到的素材列入教案"十、参考资料"，方便核查。
